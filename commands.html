Commands

Complete reference for all CLI options

Basic

bash
python src/main.py --debug
python src/main.py --version
python src/main.py --info

OptionDescriptionDefault
--cameraCamera index or RTSP URL0
--widthFrame width640
--heightFrame height480
--fpsTarget FPS30

bash

OptionDescriptionDefault
