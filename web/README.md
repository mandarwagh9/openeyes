# Website (Astro)

This directory contains the framework-based website implementation.

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Routes

- `/` -> `web/pages/index.astro`
- `/docs` (redirects to `/docs.html`) -> `web/pages/docs.astro`
- `/hardware` (redirects to `/hardware.html`) -> `web/pages/hardware.astro`
- `/demos` (redirects to `/demos.html`) -> `web/pages/demos.astro`
- `/community` (redirects to `/community.html`) -> `web/pages/community.astro`
