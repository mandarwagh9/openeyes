01. Installation

OpenEyes requires Python 3.10+ and an NVIDIA Jetson, Intel NPU, or Hailo device.

bash
# 1. Clone repository
git clone https://github.com/mandarwagh9/openeyes
cd openeyes

# 2. Install dependencies (TensorRT/CUDA required)
pip install -r requirements.txt

# 3. (Optional) Run hardware optimization script
python scripts/optimize_jetson.py

02. Quick Start

Always run the engine using the module execution syntax (-m src.main). The default resolution is 1280x720.

bash
# Basic YOLO detection pipeline
python -m src.main --camera 0

# Full multi-modal pipeline (DeepStream + MediaPipe)
python -m src.main --camera 0 --enable-face --enable-gesture --enable-pose --enable-depth

03. CLI Reference

Flag Description
--camera [ID] Camera device ID (default: 0). Use /dev/video0 if CSI camera is unavailable.
--video [FILE] Process offline video instead of live camera feed.
--enable-face Initialize MediaPipe FaceMesh (max_faces=3). Confidence threshold: 0.25.
--enable-gesture Initialize Hand tracking. Detects 8 core gestures (open_palm, peace, thumbs_up).
--enable-pose Initialize Pose estimation (33 keypoints).
--world-model Load LeWM (15M) for predictive tracking. Use --follow for target locking.

04. ROS2 Telemetry

OpenEyes publishes vision metadata natively to ROS2 nodes. Launch via MultiThreadedExecutor.

bash
ros2 launch openeyes openeyes.launch.py device:=cuda ros2:=true
Topic Payload Type
/vision/detectionsJSON (BBox, Class, Confidence)
/vision/depthJSON (Normalized depth maps)
/vision/facesJSON (Face landmarks)
/vision/gesturesJSON (String enum)
/vision/poseJSON (33-point skeletal map)
/vision/planJSON (World model prediction delta)

05. Troubleshooting

  • Face detection fails: Ensure RGBA to BGR conversion is intact in appsink. MediaPipe requires BGR format: cv2.cvtColor(frame, cv2.COLOR_RGBA2BGR).
  • CSI Camera not found: Check /dev/video0 permissions. Reboot if NVArgus daemon crashes.
  • ROS2 Topics empty: Add time.sleep(0.5) after init. Use MultiThreadedExecutor.
  • PoseData Error: PoseData is an object with a .detected attribute, not a list. Handle with [pose_result] if pose_result.detected else [].
