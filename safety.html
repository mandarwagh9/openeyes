Safety

Features

  • E-STOP — Emergency stop control
  • Velocity Limits — Max speed configuration
  • Distance Limits — Min obstacle distance
  • Health Monitor — 24/7 with auto-recovery
  • OTA Updates — Model updates + rollback

Enable

$python src/main.py --safety
$python src/main.py --safety --max-velocity 0.5 --min-distance 0.3

Config

  • --max-velocity — Max m/s (default: 1.0)
  • --min-distance — Min meters (default: 0.3)
  • --health-monitor — Enable monitoring
  • --ota-update — Enable updates
