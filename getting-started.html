Getting Started

Install

$git clone https://github.com/mandarwagh9/openeyes.git
$cd openeyes
$pip install -r requirements.txt

Run

$python src/main.py --debug

Options

$python src/main.py --world-model lewm --follow
$python src/main.py --template warehouse --debug
$python src/main.py --video input.mp4 --output out.mp4
$python src/main.py --ros2

Requirements

  • Jetson Orin Nano, Raspberry Pi 5, Intel NPU, or Hailo
  • CSI Camera, USB Webcam, or RealSense
  • Ubuntu 22.04
