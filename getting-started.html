Getting Started

Get up and running with OpenEyes in 5 minutes

Prerequisites

  • NVIDIA Jetson Orin Nano (4GB or 8GB)
  • CSI Camera (IMX219) or USB Webcam
  • Ubuntu 22.04 installed
  • Internet connection

Step 1: Clone and Install

bash 
# Clone the project
git clone https://github.com/mandarwagh9/openeyes.git
cd openeyes

# Create virtual environment
python3 -m venv venv
source venv/bin/activate

# Install requirements
pip install -r requirements.txt

Step 2: Verify Camera

For USB Webcam

bash 
# Check camera is detected
ls /dev/video*

# Test with Python
python3 -c "import cv2; cap = cv2.VideoCapture(0); print('OK' if cap.isOpened() else 'Error'); cap.release()"

For CSI Camera

bash 
# Check camera device
ls -la /dev/video*

# Test with GStreamer
gst-launch-1.0 nvarguscamerasrc sensor-id=0 ! fakesink

Step 3: Run the Vision System

bash 
# Run with debug window
python src/main.py --debug

# Run headless (no display)
python src/main.py

# Run with ROS2 publishing
python src/main.py --ros2

# Show version
python src/main.py --version

Step 4: Enable Maximum Performance (Jetson)

bash 
# One-command optimization (requires sudo)
sudo bash scripts/jetson_perf.sh

# Or manually
sudo nvpmodel -m 0
sudo jetson_clocks

Step 5: Customize (Optional)

Change Camera

bash 
# Different CSI sensor (CAM1)
python src/main.py --camera 1

# USB camera
python src/main.py --camera 0

Disable Models for Speed

bash 
# Disable extra models for maximum FPS
python src/main.py --no-face --no-gesture --no-pose --no-depth

# Run pose every 3 frames
python src/main.py --pose-every 3

Change Output Target

bash 
# Send to different host
python src/main.py --host 192.168.1.100 --port 5000
