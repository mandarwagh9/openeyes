OpenEyes GitHub

ROS2

Run with ROS2

$python src/main.py --ros2

Topics

  • /vision/detections — JSON detections
  • /vision/depth — Depth map
  • /vision/faces — Face detections
  • /vision/gestures — Gestures
  • /vision/pose — Body pose
  • /vision/status — System status

Commands

$rostopic pub /vision/command std_msgs/String "data: 'forward'"
$rostopic pub /vision/command std_msgs/String "data: 'stop'"
$rostopic pub /vision/command std_msgs/String "data: 'follow'"

Launch

$ros2 launch openeyes openeyes.launch.py
