We Give Robots Vision

A humanoid robot needs to see the world like a human does. Not just pixels — but understanding. Distance. Intent. Action.

OpenEyes runs entirely on NVIDIA Jetson — no cloud, no lag, no dependencies.

Get Started Star on GitHub

What OpenEyes Sees

🔍

Object Detection

Real-time detection of 80+ object classes. The robot sees "cup on table, 40cm away" — not just pixels.

📏

Depth Estimation

Measure distance to everything in the scene

👤

Face Detection

Who's in the room? Track and identify

👋

Gesture Recognition

Understand hand signals — stop, wave, point. "They're waving at me — that's a greeting."

🦴

Pose Estimation

Detect body positions

🎯

Object & Person Tracking

Follow specific objects or people across frames. Autonomous person following with gesture-based owner selection.

🗺️

Visual SLAM

Build maps, navigate

Quick Start

bash 
# Clone and install
git clone https://github.com/mandarwagh9/openeyes.git
cd openeyes
pip install -r requirements.txt

# Run with debug window
python src/main.py --debug
bash 
# Jetson Optimization
sudo nvpmodel -m 0
sudo jetson_clocks
