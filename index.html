🤖 We Give Robots Vision

A humanoid robot needs to see the world like a human does. Not just pixels — but understanding. Distance. Intent. Action.

OpenEyes runs entirely on NVIDIA Jetson — no cloud, no lag, no dependencies.

🚀 Quick Start ⭐ Star on GitHub

✨ Features

🔍

Object Detection

Real-time detection of 80+ object classes with YOLO

📏

Depth Estimation

Measure distance to everything in the scene using MiDaS

👤

Face Detection

Identify and track faces in real-time

👋

Gesture Recognition

Understand hand signals — stop, wave, point

🦴

Pose Estimation

Detect body positions with MediaPipe

🎯

Object Tracking

Follow specific objects across frames

🚶

Person Following

Autonomous person tracking and following

🗺️

Visual SLAM

Build maps and navigate autonomously

🛠️ Quick Start

bash 
# Clone and install
git clone https://github.com/mandarwagh9/openeyes.git
cd openeyes
pip install -r requirements.txt

# Run with debug window
python src/main.py --debug
bash 
# Jetson Optimization
sudo nvpmodel -m 0
sudo jetson_clocks
